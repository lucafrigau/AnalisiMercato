# Icone

Icone SVG progettate per AnalisiMercato. **Non vengono utilizzate** dalla build
corrente del modulo: jamovi consente icone custom solo ai moduli inclusi
ufficialmente nella library, e in quel caso le icone vanno fornite al team
jamovi che le inserisce nel client.

Le tengo qui per:

- riutilizzo futuro nel caso il modulo entri nella library jamovi;
- materiale didattico / documentazione;
- eventuale uso esterno (slide, articoli, sito).

## File

| File | Concetto rappresentato |
|---|---|
| `AnalisiMercato.svg` | Modulo: donut a 4 quadranti (metafora segmentazione) |
| `hc.svg` | Cluster Analysis Gerarchica: piccolo dendrogramma a 4 foglie |
| `ari.svg` | Confronto partizioni: diagramma di Venn |
| `catdes.svg` | Caratterizzazione: cluster di punti + etichette descrittive |

## Specifiche tecniche

- Formato SVG, `viewBox="0 0 64 64"`.
- Palette: tableau-like (`#1F77B4`, `#FF7F0E`, `#2CA02C`, `#D62728`, `#9467BD`).
- Si scalano puliti da 32×32 fino a 256×256.
- Tutti i file sono ≤ 1.1 KB.
